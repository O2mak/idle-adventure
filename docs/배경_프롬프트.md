# 가까운 풍경 띠 요청 프롬프트 (제미나이 등 그림 AI용)

배경의 나무·건물이 캐릭터에 비해 작다는 피드백 → 지금 배경은 그대로 두고, 캐릭터 바로 뒤에 큰 나무·건물만 있는 "가까운 풍경 띠"를 나라마다 한 장씩 깖.

첨부: 바탕화면 `배경_참고그림`의 그 나라 지금 배경 + `몬스터_참고그림/캐릭터_고양이.png`.

## 공통 지시문
```
The first attached image is the current background of one stage in my side-scrolling pixel art game. The attached cat is my player character and shows the pixel size and art style.
Problem: the trees and buildings in the background look too small next to the character.
Create a NEAR FOREGROUND SCENERY STRIP that will be placed right behind the characters, in front of this background.

Rules:
- Size: exactly 512 x 112 pixels, true pixel art on a strict square pixel grid (hard-edged upscale is fine), no anti-aliasing, no blur.
- The pixel size must match the cat (the cat is about 64 pixels tall). Scenery objects are big: trees about 80-110 pixels tall, buildings about 60-100 pixels tall.
- Side view, all objects stand on the bottom edge of the image (the ground line). Do not draw the ground itself.
- Sparse: 4 to 6 large objects spread along the strip with wide empty gaps between them, so the far background stays visible. Leave the vertical middle third of each 256-pixel half mostly open.
- Horizontally seamless: the left and right edges must connect when the strip is repeated.
- Same colors and mood as the attached background, slightly darker and more saturated than the far background so it reads as closer.
- Thick dark outline and 2-3 tone cel shading like the cat.
- No characters, no animals, no text, no sky, no clouds, no far mountains.
- Everything that is not an object is flat solid #FF00FF magenta.

Country and objects:
```
