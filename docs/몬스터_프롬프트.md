# 몬스터 그림 요청 프롬프트 (제미나이 등 그림 AI용)

쓰는 법: 고양이(턱시도)·코기 그림을 먼저 첨부 → 아래 공통 지시문 → 맨 끝 "Monster:" 뒤에 몬스터 한 줄. 한 번에 한 마리씩.

## 공통 지시문
```
Draw ONE game monster as pixel art in exactly the same art style as the attached cat and corgi characters.

Style rules:
- True pixel art on a strict square pixel grid: NORMAL monster = 64x64 pixels, BOSS = 128x128 pixels (upscaled with hard edges is fine, but every pixel block must be the same size). No anti-aliasing, no blur, no gradients.
- Dark purple-black 1-pixel outline around the whole body, 2-3 tone cel shading, light from the top-left, rich saturated colors like the attached characters.
- Cute but a little fierce, chibi proportions (big head, about 40% of the height), clear readable silhouette.
- Facing LEFT, slight 3/4 view, full body, standing in a neutral battle-ready pose. The feet touch the bottom edge.
- Keep arms, legs, tail and weapons slightly apart from the body (not overlapping the torso), so each body part can be animated separately.
- Background: one flat solid color (#FF00FF magenta) or transparent. No ground, no shadow, no scenery, no text, no frame.
- Only one character in the image.

Monster:
```
